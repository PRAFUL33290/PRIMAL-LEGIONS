🔌 Transférer ses fichiers avec Rsync via SSH

Guide complet pour utiliser rsync sur un port SSH personnalisé (65002) — la solution pour les hébergeurs comme Hostinger.

🎯 Le contexte

Vous souhaitez transférer les fichiers de votre serveur distant vers votre machine locale. Votre serveur utilise le port 65002 au lieu du port SSH standard (22). Il faut donc indiquer à rsync la bonne « porte » d'entrée.

💡 Pourquoi le port 65002 ? Par défaut, SSH utilise le port 22. Certains hébergeurs comme Hostinger modifient ce port pour des raisons de sécurité. Il faut donc le préciser dans la commande.

💻 La commande finale et complète

Copiez et collez cette commande exactement dans votre terminal :

Bash rsync -avzP -e "ssh -p 65002" u734339183@62.72.37.40:/home/u734339183/domains/parvati-india.fr/ "/Users/julienguerrier/Desktop/PARVATI INDIA/"

🔎 Explication des paramètres

rsync L'outil de synchronisation de fichiers -a Mode archive : conserve les permissions, dates, liens symboliques, etc. -v Mode verbose : affiche les détails du transfert -z Compression pendant le transfert pour plus de rapidité -P Affiche la progression et permet de reprendre un transfert interrompu -e "ssh -p 65002" Force rsync à utiliser SSH sur le port 65002 au lieu du port 22 par défaut u734339183@62.72.37.40: Identifiant et adresse IP du serveur distant /home/.../parvati-india.fr/ Chemin des fichiers source sur le serveur "/Users/.../PARVATI INDIA/" Chemin de destination sur votre machine locale (entre guillemets car il contient un espace)

✅ Ce qui va se passer ensuite

  1. Le message de sécurité : Si c'est la première fois que vous vous connectez, le terminal affichera : "The authenticity of host... can't be established". Tapez simplement yes et appuyez sur Entrée.
  2. Le mot de passe : On vous demandera ensuite le mot de passe SSH (celui qui correspond au bouton « Changer » sur votre panneau d'hébergement).
  3. Le transfert : Vous verrez la liste des fichiers défiler avec leur vitesse de transfert et la progression en pourcentage.

⚠️ Note importante : Quand vous tapez le mot de passe, rien ne s'affiche à l'écran (pas même des étoiles ****). C'est normal et c'est une mesure de sécurité. Tapez-le à l'aveugle et validez avec Entrée.

🔐 Pourquoi ajouter -e "ssh -p 65002" ?

Par défaut, rsync essaie de se connecter sur le port 22. Comme Hostinger utilise le port 65002 pour la sécurité, cette option force rsync à utiliser le bon chemin.

Sans cette option, vous obtiendriez une erreur de connexion refusée (Connection refused) car le serveur n'écoute pas sur le port 22.

🛠️ Astuce : Vous pouvez adapter cette commande à n'importe quel port SSH personnalisé en changeant simplement le numéro après -p.
